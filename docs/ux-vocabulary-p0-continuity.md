# Vocabulaire auteur — Continuité

Cette tranche P0 applique le glossaire UX de #263 aux composants transverses de la Continuité.

## Principes

- L’interface parle d’histoire, de continuité, d’informations confirmées et de conséquences d’une modification.
- Les termes d’implémentation restent dans les API, types et fonctions internes.
- Les identifiants techniques ne sont pas exposés lorsqu’ils n’aident pas l’auteur à prendre une décision.

## Correspondances

| Terme technique | Terme visible |
| --- | --- |
| Canon | Continuité / informations confirmées |
| Canon fact | Information confirmée |
| Assertion | Information / proposition |
| Consistency analysis | Vérification de la continuité |
| Impact analysis | Mesurer l’impact |

| Rationale | Note / raison |

| Accepted | Confirmée |
| Rejected | Écartée |
