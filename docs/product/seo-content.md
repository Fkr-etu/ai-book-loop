# Book Loop — SEO content strategy

## Goal

Build organic discovery around the problems Book Loop actually solves: writing long-form stories with AI, maintaining narrative continuity and keeping a durable story reference under author control.

## Editorial rule

Every guide must solve a real reader problem before mentioning Book Loop. Content should be original, practical and useful without requiring the product. Avoid keyword stuffing, templated pages and mass-generated articles.

## Initial hub

- `/guides/ecrire-un-roman-avec-ia`
- `/guides/garder-coherence-roman-ia`
- `/guides/bible-narrative`
- `/guides/eviter-contradictions-roman`

## Internal linking

Each guide links back to `/guides`. Future guides should link to closely related guides and, where relevant, to public product pages. Private application routes must never be used as SEO landing pages.

## Acquisition funnel

`Recherche → guide utile → problème de continuité → Canon narratif → Book Loop → démarrage gratuit`

The editorial objective is category association, not traffic volume alone.
