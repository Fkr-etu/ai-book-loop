# Approved Chapter → Canon Flow

An approved chapter is the boundary between author-approved manuscript content and proposed Canon knowledge.

```text
chapter version
     ↓
author approval
     ↓
persisted source document + evidence
     ↓
proposed assertions
     ↓
deterministic conflict detection
     ↓
human assertion review
     ↓
CanonicalFact
```

Approval never promotes an assertion directly to `CanonicalFact`. The sync stage only creates traceable proposals and conflicts; human review remains authoritative.
